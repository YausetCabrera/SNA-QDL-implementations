# SNA-QDL Protocol Simulation

This repository contains the source code developed to **simulate, evaluate, and visualize the behavior of the (primitive) SNA-QDL quantum protocol**. Simulations are implemented using **Qiskit** and cover a range of experimental scenarios, from scalability assessment under ideal conditions to robustness analysis under different quantum noise channels.

The code presented in this repository forms part of the research, experimental evaluation, and validation of the SNA-QDL protocol for academic publication.

---

The repository is organized into four main scripts, each addressing a specific aspect of the protocol's performance and analysis.

* **Scalability Benchmark** — `raw_simulation.py`
Evaluates the computational cost of the protocol as the size of the transmitted message increases. Encodes classical symbols (qudits with dimension $d=8$) into groups of three qubits, applies Quantum Fourier Transforms (QFT), and performs phase transformations based on a secret key. The simulation uses the **Matrix Product State (MPS)** method provided by Qiskit Aer, enabling the simulation of large-scale quantum circuits that would otherwise require prohibitive amounts of memory when using conventional state-vector simulators.

* **Local Noise Simulation** — `noise_simulation_loc.py`
Evaluates the performance of the protocol under a realistic hardware-inspired noise model. Introduces a noise model based on a generic IBM Quantum backend (`GenericBackendV2`) during the execution of the protocol. This simulation provides insight into the protocol's behavior under realistic hardware imperfections and helps identify how and where communication errors arise.

* **Interactive Visualization Tool** — `information_simulation.py`
Provides an interactive environment for exploring the mathematical and statistical properties underlying the protocol. Simulates the statistical properties of the density matrix generated by the protocol. Users can configure parameters such as the qudit dimension, number of symbols, and leakage rate. It provides an intuitive visual representation of how the secret-key size ($\kappa$) affects the distribution of information. In particular, users can observe how the density matrix becomes increasingly dispersed as the key size increases.

* **Error Channel Analysis** — `error_channels_simulation.py`
Provides a dedicated benchmark for evaluating the robustness of the SNA-QDL protocol against different types of quantum noise. Allows the user to select between three noise configurations:

  * `pauli`: Pauli noise / depolarizing effects
  * `damping`: Amplitude Damping channel
  * `both`: Combined Pauli and Amplitude Damping noise

This analysis isolates the effects of different noise mechanisms, making it possible to evaluate which types of hardware imperfections have the greatest impact on the performance and reliability of the SNA-QDL protocol.


## Installation and Usage

### Requirements

Make sure that **Python 3.8 or later** is installed on your system. Using a virtual environment is strongly recommended.

### 1. Clone the repository

```bash
git clone https://github.com/YausetCabrera/SNA-QDL-implementations.git
cd repository
```

### 2. Install required dependencies

Install all required Python dependencies using the provided `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### 3. Run the simulations

Each script can be executed independently depending on the analysis you wish to perform. For instance, to launch the interactive visualization tool:

```bash
python information_simulation.py
```
